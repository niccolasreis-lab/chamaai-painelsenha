Guia de Instalação Rápida e Implantação em Rede

Como o sistema funciona?

O ChamaAí foi desenhado para ser rápido e independente de internet externa. Ele funciona com o conceito de Servidor Central. Você fará a instalação do sistema completo em apenas UM computador principal, e todos os outros equipamentos (Totens, Celulares, Guichês) acessarão o sistema via rede local pelo navegador (Google Chrome).

1
Instalação no Computador Principal (Telão / Servidor)

Este computador será o cérebro da operação. Geralmente é o PC ligado à TV (Telão) ou o computador da Recepção.

Passo a passo:

  1. Copie o arquivo ChamaAí Setup 1.0.0.exe para este computador.
  2. Execute o instalador e avance até o final.
  3. Após instalar, o sistema abrirá a Tela Inicial preta com os botões.
  4. Clique no botão azul Telão para iniciar a tela de exibição para os clientes.
Muito Importante: Para que os outros computadores consigam acessar o sistema, você precisa descobrir o IP deste computador na rede (Exemplo: 192.168.1.100). É altamente recomendado configurar o roteador para fornecer um IP Fixo para esta máquina.
2
Instalação no Totem de Senhas (com Impressora)

Se o seu Totem utilizar uma impressora térmica USB (Não-rede), você precisará instalar o programa nele para liberar o acesso físico à impressora.

Passo a passo:

  1. Instale o mesmo ChamaAí Setup 1.0.0.exe no computador do Totem.
  2. Abra o sistema. Na tela inicial, olhe na parte inferior e clique no botão:
    "Modo: Servidor Local (Standalone)"
  3. Uma janela vai abrir pedindo um IP. Digite o IP do Computador Principal (Telão) que você descobriu no Passo 1 (Ex: 192.168.1.100).
  4. O sistema vai recarregar e o botão inferior mudará para "Conectado ao Servidor: 192.168.1.100".
  5. Agora é só clicar no botão vermelho Totem. Ele irá se conectar ao Telão, mas imprimirá localmente!
A impressora deve estar previamente instalada no Windows (com o driver do fabricante) e configurada nas opções de Admin do sistema.
3
Acesso dos Operadores (Guichês e Celulares)

Para quem vai chamar as senhas, o processo é o mais fácil de todos: Não precisa instalar nada.

Passo a passo:

  1. No computador ou celular do operador, abra o Google Chrome.
  2. Na barra de endereços, digite o IP do Servidor seguido de :3000/#/operador
http://192.168.1.100:3000/#/operador

4
Painel de Administração

O painel administrativo também é acessado pelo navegador de qualquer máquina na rede.

  • Endereço: http://IP_DO_SERVIDOR:3000/#/admin
  • Usuário padrão: admin
  • Senha padrão: admin

No painel você poderá configurar o nome da loja, trocar os vídeos do Telão, cadastrar a impressora, ajustar as filas e monitorar relatórios.

Segurança dos Dados: O sistema realiza um backup diário automático (sempre à meia-noite) na pasta Documentos/ChamaAi_Backups do Computador Principal.
