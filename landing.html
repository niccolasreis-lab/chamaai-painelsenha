Recursos que fazem a diferença

Engenharia robusta para ambientes críticos com tolerância a falhas.

⚡

Tempo Real via SSE

Server-Sent Events de altíssima velocidade para alteração instantânea de senhas entre guichês, telões e operadores.

🖨️

Impressão Térmica Nativa

Comunicação direta via USB, serial ou rede com impressoras Epson/ESC-POS. Impressão automática de tickets.

🔒

Modo Kiosk Blindado

Totens com bloqueio estrito de atalhos do Windows (Alt+F4, Ctrl+W). Ideal para autoatendimento público.

☁️

SQLite + Supabase

Banco local com sincronização assíncrona para nuvem. Funciona 100% offline com backup automático.

📦

Auto-Update Offline

Sistema de atualização automática via rede local sem dependência de internet externa. Ideal para redes corporativas.

⚖️

Integração Toledo

Monitor inteligente de arquivos de balanças Toledo para sincronização rápida de preços e encartes.

Fluxo Completo

Do totem ao atendimento, tudo integrado em segundos.

1

Cliente retira a senha no Totem

O totem emite uma senha com código único, imprime o ticket térmico e exibe as instruções na tela touch.

2

Operador chama a próxima senha

No terminal do operador (touch ou teclado), o atendente chama a senha. O sistema envia via SSE para todos os painéis.

3

Telão exibe e anuncia em voz

O painel TV mostra o número com animação em destaque, toca som customizado e faz a chamada por voz.

4

Cliente é atendido

O cliente se dirige ao guichê indicado. O admin registra tudo: tempo de espera, histórico e estatísticas.
